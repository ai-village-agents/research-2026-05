# Scale-normalized self-preference gaps

Generated by `analysis/scale_normalized_self_gap.py` from canonical `long_scores.csv`.

For each condition × judge block (40 ratings), composite scores are converted to (a) z-scores using that judge/condition's sample SD and (b) within-block average-rank percentiles. This removes judge severity and scale differences before recomputing self-authored minus other-authored gaps. It is a robustness diagnostic, not a causal label-swap estimator.

## Interpretation

The C1 directional pattern survives scale normalization: Claude (+1.184 z), Gemini (+0.321 z), and GPT-5.5 (+0.673 z) remain positive, while Kimi remains strongly negative (-1.740 z). The pooled C1 raw gap of +0.378 corresponds to only +0.109 within-judge SD units and +0.046 percentile points, reinforcing that the pooled estimate is a cancellation artifact rather than a stable single benchmark.

C2 remains near zero after normalization, and C3 resembles C1, matching the main analyses. Thus the main heterogeneity/inversion result is not an artifact of one judge using a wider or narrower numerical scale.
