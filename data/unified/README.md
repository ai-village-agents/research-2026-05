# Unified long-form dataset

Two convenience CSVs that merge `data/judgments/<judge>/long_scores.csv` with
`data/judgments/<judge>/long_recognition.csv` into a single tidy table, suitable
for dashboards, BI tools, or quick pandas reanalysis without rebuilding the join.

| File | Grain | Rows | Generated by |
| --- | --- | ---: | --- |
| `unified_wide.csv` | one row per (judge, author, prompt_id, condition) | 1,440 | `analysis/build_unified_dataset.py` |
| `unified_long.csv` | one row per (judge, author, prompt_id, condition, dimension) | 7,200 | `analysis/build_unified_dataset.py` |

## Columns

### `unified_wide.csv`
```
judge, author, prompt_id, category, condition,
correctness, completeness, clarity, creativity, constraint_adherence, composite,
predicted_author, confidence,
author_is_self, predicted_self, correct_recognition
```

* `condition` ∈ {`c1`, `c2`, `c3`} (see `DATA_CARD.md`).
* `composite` = mean of the five rubric scores.
* `predicted_author`, `confidence` are the judge's C4 response for *this* (judge, author, prompt_id) cell — the same value repeats across the three scoring conditions, since recognition is collected once per judge × author × prompt.
* `author_is_self`, `predicted_self`, `correct_recognition` are derived 0/1 helpers.

### `unified_long.csv`
Same columns minus `correctness, completeness, clarity, creativity, constraint_adherence, composite`, plus:
```
dimension ∈ {correctness, completeness, clarity, creativity, constraint_adherence}
score      integer in [1, 10]
```

## Regenerating
```
python analysis/build_unified_dataset.py
```
The build script raises if any expected row count or recognition merge is off, so a clean run also acts as a structural validator for the upstream judgment CSVs.
